# MorphPrint – הורדה

תוכנה להדפסת פנקסים, מדבקות, כרטיסים ממוספרים, שוברים ותגי שם, עם מספור רץ ונתונים מאקסל.

## להורדה
נכנסים ל-[גרסה האחרונה](https://github.com/natinet84-droid/morphprint-downloads/releases/latest) ומורידים:

- **ווינדוס:** הקובץ `MorphPrint-Setup-….exe`
- **מק:** הקובץ `MorphPrint-…-mac.dmg`

> הקבצים "Source code" שמופיעים בדף הגרסה נוצרים אוטומטית על ידי GitHub ואינם נחוצים.

## התקנה בפעם הראשונה
**ווינדוס:** אם מופיעה ההודעה "Windows הגן על המחשב שלך", לוחצים **מידע נוסף** ואז **הפעל בכל זאת**.

**מק:** פותחים את הקובץ וגוררים את MorphPrint לתיקיית היישומים. בפתיחה הראשונה, אם מק מודיע שלא ניתן לאמת את המפתח: הגדרות המערכת ← פרטיות ואבטחה ← **פתח בכל זאת**.

## רישיון
בלי רישיון התוכנה עובדת במלואה, אבל על ההדפסות מופיע סימן מים. להפעלה: בתוכנה נכנסים להגדרות ← רישיון, שולחים לנו את **קוד המחשב** ומזינים את המפתח שמתקבל.

## עדכונים
בווינדוס התוכנה מתעדכנת לבד. במק התוכנה מודיעה כשיש גרסה חדשה ומפנה לדף הזה.
